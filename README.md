# AI GUILD IZUMO

出雲でAIを学び、つくり、共有するコミュニティの公式サイト。

## Website
Static HTML/CSS, intentionally dependency-free. Edit `index.html` to add member projects and replace the placeholder Discord URL.

## Brand assets
The `assets/` directory contains scalable SVG artwork for the website banner, poster, and Japanese 91 × 55 mm business card.

## Deploy
GitHub Pages is configured through `.github/workflows/pages.yml`.
